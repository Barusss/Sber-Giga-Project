# СИНТЕТИЧЕСКИЕ ТЕХНИЧЕСКИЕ УСЛОВИЯ № SYN-TU-001

> Документ создан только для проверки модуля ТУ ↔ ЗнП. Не является реальным ТУ.

**Объект:** синтетический административно-бытовой комплекс.

## 1. Общие сведения

1.1. Максимальная присоединяемая мощность энергопринимающих устройств составляет 726,9 кВт.

1.2. Номинальное напряжение в точке присоединения — 0,4 кВ.

1.3. Электроснабжение предусмотреть по II категории надёжности.

## 2. Точка присоединения

2.1. Точку присоединения разместить на границе земельного участка заявителя.

## 3. Учёт электроэнергии

3.1. Прибор учёта электрической энергии должен иметь класс точности не ниже 0,5S.

## 4. Защита и оборудование

4.1. Предусмотреть установку ограничителя перенапряжений нелинейного.

4.2. Выполнить огнезащиту кабельных линий в электротехнических помещениях.
