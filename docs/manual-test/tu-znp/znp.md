**Объект:** синтетический административно-бытовой комплекс.

## 1. Мощность и напряжение

1.1. Расчётная максимальная мощность присоединяемых энергопринимающих устройств — 726,9 кВт.

1.2. Присоединение выполнить к электрической сети напряжением 0,4 кВ.

1.3. Электроснабжение предусмотреть по II категории надёжности.

## 2. Точка присоединения

2.1. Место подключения определить по меже, выделенной застройщику.

## 3. Учёт электроэнергии

3.1. Прибор учёта электрической энергии принять класса точности 1,0.

## 4. Защита и оборудование

4.1. Предусмотреть установку ограничителя перенапряжений нелинейного.

4.2. Выполнить заземление электроустановки.
