## Обнаруженный дефект исходного PR и исправление

В 648a7b9 сохранялся обход границы контейнера через текст: строка таблицы №1 → ненумерованное условное примечание → ненумерованный заголовок таблицы №2 объединялись в один атом. Причина: `_container_boundary` сравнивал новую таблицу только с последним текстовым фрагментом, теряя прежнюю таблицу группы.

Сначала добавлен test_prose_note_cannot_bridge_two_distinct_tables, воспроизводящий ошибку (ожидалось 2 атома, получен 1). Затем в extraction.py добавлено сравнение с последним табличным источником всей текущей группы. Примечание остаётся при первой таблице; вторая начинается отдельно. Никаких предупреждений не отключено. Изменение узкое: 11 строк production-кода и одна регрессия.
